# 이동찬 포트폴리오

AI 서비스 개발자 이동찬의 포트폴리오 사이트입니다. 순수 HTML/CSS/JS 정적 페이지이며 GitHub Pages로 배포합니다.

- `index.html` — 페이지 구조와 내용 (Home · About · Skills · Projects · Deep Dive · Experience · Contact)
- `style.css` — 스타일 (어두운 테마 하나, 반응형)
- `script.js` — 첫 화면의 프로젝트 대륙 지구본과 기술 궤도, 프로젝트 분류, 시연 창, 메일 폼
- `img/` — 프로젝트 화면과 기술 로고 (로고: Simple Icons, Devicon)

로컬 확인: `index.html`을 브라우저에서 열면 됩니다.
